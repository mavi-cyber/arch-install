An interactive Arch Linux installer

The Installation guide, §1.1 to §4, in one script.

It asks a few questions, shows you exactly what it's about to do, and only touches the disk after you type its name. Every step is tagged with the ArchWiki section it comes from.

This project

arch-install.sh

A plain bash script that follows the Installation guide line by line. Read it top to bottom, tweak it, and reuse your saved answers on every reinstall.

root@archiso ~ # bash arch-install.sh --config answers.conf
  • Every step labelled with its guide section
  • --dry-run walks every question without touching a disk

Before you boot

Getting the Arch ISO

Always from the official site. These four steps are §1.1 to §1.4 of the Installation guide.

  1. Download

    From archlinux.org/download, grab archlinux-YYYY.MM.DD-x86_64.iso by BitTorrent or from a mirror near you.

  2. Check it

    Compare with the SHA256 on the download page.

    # Windows PowerShell
Get-FileHash .\archlinux-*.iso
# Linux
sha256sum archlinux-*.iso

  3. Write a USB stick

    2 GB or more, it gets wiped. On Windows use Rufus (try DD Image mode if it won't boot) or Ventoy. On Linux, dd to the whole device, like /dev/sdX.

  4. Boot it

    Turn off Secure Boot, pick the stick from the boot menu (F12, F11, F8 or Esc) and choose Arch Linux install medium. You land on a root shell.

On the live ISO

Getting the script

Get online first. Ethernet just works; for Wi-Fi use iwctl, or run the script anyway and it walks you through connecting.

# curl -fLO https://raw.githubusercontent.com/mavi-cyber/arch-install/main/arch-install.sh
# curl -fLO https://raw.githubusercontent.com/mavi-cyber/arch-install/main/arch-install.sh.sha256
# sha256sum -c arch-install.sh.sha256 && bash arch-install.sh

The last line only starts the installer when the check prints arch-install.sh: OK.

Copy arch-install.sh onto any FAT32 or exFAT stick, or next to the ISO on a Ventoy stick. Then on the ISO:

# lsblk
# mount --mkdir /dev/sdX1 /media/usb
# bash /media/usb/arch-install.sh

You still need internet later for the packages; the script helps you connect.

On the PC that has the script, in its folder:

python -m http.server 8000

On the ISO:

# curl -fO http://<that-pc-ip>:8000/arch-install.sh

On Windows, allow Python through the firewall when it asks.

Checking the download

Don't run a script that partitions your disk without checking it first. The SHA-256 of arch-install.sh v1.0.0:

17ab5eff8b80134ba636d866a1284d5231ec87f12f5ce9ab35ca3a25625f196c

Got it from a USB stick or another PC? Run sha256sum arch-install.sh and compare. On FAILED, delete it and download again.

Running it

Nothing is written until you say so

  1. Answer

    Every question has a sane default. Type ? at the keymap, time zone or locale prompt to list what's valid.

  2. Review

    A summary screen shows the whole plan. Change any section, save your answers, or quit.

  3. Confirm

    Type the disk's name, like nvme0n1. Mashing Enter can't wipe the wrong drive.

  4. Install

    It installs, configures, saves your answers to /root/arch-install.conf and offers to reboot.

FlagWhat it does
-c, --config FILEPre-fills answers from a file. Anything missing or invalid is still asked. Passwords, disks and partitions are always asked.
-p, --post FILERuns your own script inside the new system at the end: dotfiles, an AUR helper, anything.
-n, --dry-runAsks everything and shows the plan, but touches nothing.

Saved answers live on the new system's disk. Copy /root/arch-install.conf to your repo or a USB stick before your next reinstall wipes it.

What it does, by guide section

Following the Installation guide

If the script and the wiki ever disagree, trust the wiki.

§1.5

Keyboard and font

Any console keymap, plus an optional large Terminus font for HiDPI screens. Both carry over.

§1.6

Boot mode

Detects 64-bit UEFI, 32-bit UEFI, BIOS, or board firmware without UEFI.

§1.7-1.8

Internet and clock

Guided Wi-Fi with iwctl when offline, then waits for NTP so signatures don't fail.

§1.9

Partitioning

Auto wipes the disk for GPT (or MBR on old BIOS). Manual opens cfdisk for dual boot and keeps an existing EFI partition by default.

§1.10

File systems

ext4, Btrfs with subvolumes and zstd, XFS or F2FS. Optional LUKS2 encryption. Swap as zram, a file, a partition, or none.

§2.1

Mirrors

Keep them, rank the fastest for your country with reflector, or edit by hand.

§2.2

Packages

Kernel, firmware, microcode, editor, network, and optionally GNOME, KDE Plasma or Xfce. Every package is checked before the disk is touched.

§3.1-3.5

System config

fstab by UUID, time zone, locales, hostname, and NetworkManager or systemd-networkd with iwd.

§3.6-3.7

Initramfs and accounts

Encryption hook when needed, root password or locked root, and a sudo user.

§3.8

Boot loader

systemd-boot on UEFI, or GRUB on UEFI and BIOS with os-prober for dual boot.

Storage

Any disk you can plug in

HDDs, SATA SSDs, NVMe, eMMC and SD cards, USB drives and VM disks. It hides the boot medium, loop devices, optical drives, zram and the eMMC boot areas.

sda1 · vda1 · xvda1  /  nvme0n1p1 · mmcblk0p1: partition names are worked out for you

SSD, NVMe, eMMC

Optional whole-drive TRIM, noatime, the weekly fstrim.timer, and TRIM through LUKS. Less wear, still fast.

Advanced Format

Shows logical and physical sector sizes, and tells NVMe owners if native 4K mode is available. It never reformats for you.

USB drives

A portable install that boots on other PCs: every driver in the initramfs, both microcodes, the fallback EFI path.

CPU architectures

x86_64 first, ports welcome

Official Arch Linux is x86_64 only. The others are independent community ports with their own ISOs and repositories, not run by Arch Linux, so ask their forums for help.

ArchDistributionStatusNotes
x86_64Arch LinuxMain target64-bit UEFI, 32-bit UEFI and BIOS.
i686Arch Linux 32PortBoot their ISO and run it. GRUB for BIOS and UEFI.
aarch64Arch Linux ARMPortRun it from an ALARM system. UEFI machines get systemd-boot or GRUB; boards like the Raspberry Pi need their own boot setup afterwards.
armv7hArch Linux ARMPortSame as aarch64.
riscv64Arch Linux RISC-VBest effortExpect rough edges.

Try it in a virtual machine first: UEFI and BIOS, auto and manual layouts, with and without encryption. Found a bug? Open an issue on GitHub with /var/log/arch-install.log attached.
